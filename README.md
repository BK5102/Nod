# Nod

An AI bookkeeper that pays the routine bills and asks a person before anything risky.

Nod is an AI bookkeeper for small nonprofits. It pays routine bills by itself and stops to ask a person before anything that looks risky. It still works safely when the person approving can only send one slow, shaky signal, like a single blink or button press, because it treats that signal as a hint, not a final yes. Every decision gets a receipt showing who approved what and how sure they were.

## The problem

An AI that pays bills needs a person to say yes before risky payments. But if that person can only send one slow, shaky signal (a brain-computer interface or a single switch), the yes is either unsafe (accidental approvals) or a rubber stamp. And no finance system records how trustworthy a yes was.

## Status

Prototype, built at Cal Hacks 13.0. The approval signal in the demo is SIMULATED. No medical claims.
