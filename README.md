# Nod
Sign-off you can trust, even from one small signal.

### 
Nod is an accounts payable agent for small nonprofits whose finance leads can approve with only one slow, noisy signal. It pays within a mandate, asks only when rules say it matters, treats a noisy approval as evidence, and proves with a receipt and canary invoices that the approval was real.


Tagline: An AI bookkeeper that pays the routine bills and asks a person before anything risky.

Description: Nod is an AI bookkeeper for small nonprofits. It pays routine bills by itself and stops to ask a person before anything that looks risky. It still works safely when the person approving can only send one slow, shaky signal, like a single blink or button press, because it treats that signal as a hint, not a final yes. Every decision gets a receipt showing who approved what and how sure they were.

Problem: An AI that pays bills needs a person to say yes before risky payments. But if that person can only send one slow, shaky signal (a brain-computer interface or a single switch), the yes is either unsafe (accidental approvals) or a rubber stamp. And no finance system records how trustworthy a yes was.
